 Vehicle Management System (Java)

 Project Overview

The **Vehicle Management System** is a Java console-based application developed to manage vehicle records efficiently. It allows an administrator to add, view, search, update, and delete vehicle information through a simple menu-driven interface.

This project demonstrates the use of **Object-Oriented Programming (OOP)** concepts, **ArrayList**, **Scanner**, and basic **CRUD (Create, Read, Update, Delete)** operations in Java.

Features

*Admin Login Authentication
*  Add New Vehicle
*  View All Vehicles
*  Search Vehicle by Vehicle Number
*  Update Vehicle Details
*  Delete Vehicle Record
*  Display Total Number of Vehicles
*  Exit the Application

 Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner Class
* Console-Based User Interface
